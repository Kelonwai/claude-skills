About

Written and maintained by Kelon, a technical director in Hong Kong who ships client work with agents every day. Every skill in this repo was tested against baseline agent behaviour before release: watch it fail, write against the failure, then keep the dogfood log in the open.

If a skill never watched an agent fail, it’s documentation.
