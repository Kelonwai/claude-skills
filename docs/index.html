Notes on building Claude Code skills

Skills that watched an agent fail first.

A Claude Code skill is a folder holding a SKILL.md that the agent loads by itself when your request matches it — standing instructions for a recurring task, not a prompt you paste each time. This repo gives you three, and every one of them was TDD-tested against baseline agent behaviour before release: it exists because agents demonstrably get it wrong without it. The dogfood logs that drove each edit are in the repo, unedited.

Install npx skills add Kelonwai/claude-skills

The three skills

  • ★ testing-with-synthetic-users

    Synthetic users with real motivations walk your live deployment round after round; findings get triaged, fixed, redeployed and re-tested from fresh angles until a full round comes back clean. A loop with an exit condition, not a QA checklist.

  • ★ choosing-agent-models

    Routes each subagent you dispatch by the nature of its task — taste and judgment to the top tier, research and implementation to the mid tier, mechanical bulk to the small tier, and when in doubt no override at all.

  • ★ writing-good-skills

    Seven structural checks for a SKILL.md, distilled from baseline-testing agents who wrote skills naturally and failed three of them the same way every time.

Method

  1. RedRun the scenario on an agent without the skill; document exactly how it fails.
  2. GreenWrite the skill against those specific failures; verify the agent now complies.
  3. RefactorDogfood on real work; close the rationalization loopholes agents find.

If a skill never watched an agent fail, it’s documentation, not a skill.
